# 租住调查

本地合成业务资料。人名标识、去向、机构和观测均为虚构，不接入外部系统。

## 输入约定

`data/supplies.json` 以表名组织记录；`data/fields.json` 列出字段及该资料出现的值类型。

金额以元计；`period` 是租约开始所在季度，`rent` 与 `income` 均为月口径。`rent` 是不含 `utilities` 的月租，`free_days` 是首个计租月免除天数；资料约定折合月租使用 30 天。收入闭区间两个端点均可取，`null` 表示无证据。`lease_id` 是两方对账编号，`line` 是报送行号；一份租约在一季只纳入一个住户抽样单位。抽样登记按 `panel` 独立抽取住户，同一 `panel` 内重复报送不增加覆盖。
`areas` 声明片区组归属。`standard_weights` 是各发布地域固定的基期分层构成（住户类型加签约阶段），不随当期证据变化；`coverage` 为每层每季最低有效住户数。租住负担按当季首个计租月实际租金与月收入比较，审议阈值以百分点记录；存量高负担阈值不等于趋势阈值。用抽样权重计算基本分布，住户抽样波动须有区间说明，区间方法未指定。`amendments` 记录核验生效后可以更正的事实，不覆盖过去的审议记录；`council` 是已经发生的业务动作。

## 资料检查

在 Linux 上使用 Python 3.11 及标准库，无需安装第三方包。运行 `python3 -m unittest discover -s tests -v` 检查表字段、类型和关键关联。当前仓库只包含业务来源资料及检查，尚无分析结果或业务操作入口。
